# indonesian_twitter_depression_detection

## Dataset
Due to privacy considerations, datasets are not included in this repository.

### Depression Dataset
- **Source**: Private dataset
- **Format**: CSV with columns: `full_text`, `label`

### Emotion Dataset
- **Source**: Twitter Emotion Dataset
- **Download**: [https://www.kaggle.com/...](https://github.com/meisaputri21/Indonesian-Twitter-Emotion-Dataset.git)](link)
- **Format**: CSV with columns: `tweet`, `label`

### Setup Instructions
1. Download datasets from above links
2. Place in `MyDrive/depression_detection/data/`
3. Rename files to:
   - `depression_dataset.csv`
   - `emotion_dataset.csv`
